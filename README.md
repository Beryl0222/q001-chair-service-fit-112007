# 座椅换件中的规格兼容与安全交付

门店售后组收集的客户留言、维修记录、配件说明和远程检查卡。型号、地点和维修业务均为合成内容。

资料为 UTF-8 JSON。各类原始记录按编号分组，字段约定见 [资料格式](data/资料格式.md)。资料浏览命令会原样输出记录，添加 `--list` 可只查看各类数量。

使用 Python 3.11，命令只依赖标准库。请在项目根目录运行。

```sh
python3 inspect_records.py data/records.json --list
python3 -m unittest discover -s tests -v
```

## 换件决定引擎（advisor.py）

[`advisor.py`](advisor.py) 从同一资料包读取维修往来、供应商配件说明和远程检查手册，
按“证据 → 仍成立的装配解释（可能世界）→ 组合安全评估 → 检查推荐 → 生命周期处置”
给出每张维修单的决定。安全判定只采用 `authority=engineering` 的说明，
`advertising`（如 I5“适配轻帆二代，旧椅即插即用”）不能覆盖工程禁令。

```sh
# 中文决定报告（终端）
python3 advisor.py data/records.json

# 写入 Markdown 报告
python3 advisor.py data/records.json --report decisions_report.md

# 整张资料包的机器可读决定
python3 advisor.py data/records.json --json > decisions.json

# 单张维修单 / 联络员视图
python3 advisor.py data/records.json --order OX3
python3 advisor.py data/records.json --liaison OX4
python3 advisor.py data/records.json --liaison        # 所有已寄出 + 挂起承诺
```

也可作为库使用：`from advisor import analyze, advise_order, Session, liaison_dossier`
（这些名称也由 `inspect_records` 惰性转出）。

### 决定口径

1. **别名先到型号**：“轻帆/轻帆二代”同时对应 CY-B17（M1，小口）和 CY-C17（M2，大口），
   系列名/包装名不能决定接口；“轻帆城店款”才是 CY-D18（M3，大口）。
2. **尺寸与单位归一为毫米**：四十八毫米 = 48 mm（R48），五点二厘米 = 52 mm（R52）；
   “肩部要 52、单位没记”保留缺单位留痕，只按工程规格唯一匹配到 R52。
3. **表述分可信度**：客户猜测（“我猜”“大概”）不作事实；客户答复、来件抄录、
   工程师初检/回单、工程复测分级，冲突时当前决定取最高优先级证据，旧表述仍留在时间线与档案里。
4. **历史换架不当成现状**：A3 说明“换过旧架”是师傅让临时试装 F19、随后拆下；
   与 S2“拆下 F19、装的是 F20”一致，当前脚架只认 F20。
5. **组合约束逐条执行**：R48 仅小口；大口用 R48 必须 J03 + F20（I1）；
   J03 配 R48、禁与 F19 同装、标牌 CY-D18 也禁用（I2）；R52（52 mm）大口直接配 F20（I3）；
   F19 只用于原批小口、无转接座版本（I3/I6）。
6. **可能世界拦截**：枚举尚未被证据排除的型号/脚架/转接座组合；
   只要有一个世界会让拟寄组合触发工程禁令，该组合就不是可交付换件。
7. **答复不收窄规则**：只有正向/明确的观察才收窄候选；“挡住/没看出来”记为无法辨认，
   不等于“没有银环/J03”。`Session.add_reply()` 可在新答复到达后从当前已知情况重算下一问。
8. **检查安全与区分度**：C1（抄外露完整铭牌、不推椅）对所有候选安全；
   C3（空椅转靠背）以“已排除底盘与脚架松脱并确认直立”为前提——A1 仍报告底盘晃，
   因此 OX3 现在不得做 C3，也不能让顾客坐上去或翻椅。安全且能区分候选时才比较 effort；
   远程手段被挡或不安全、而真正的区分只剩批次卡对开口/刻印/紧固时，明确转 C4 到店/上门。
9. **交付档案**：承诺/出库行的实际部件、`verified` 答复对应的检查卡与客户原话、
   自带初检结论、出货单和引用的 I1–I6 依据全部保留；出库/出货事实不按后续复测改写。
10. **复测后处置**：已承诺未寄 → `promised_suspended_review`（挂起待复核，冻结拣发）；
    已寄出 → `shipped_liaison_review`，由联络员查“当时确认了什么、寄了什么、
    现在仍可能不安全的装配”，再判断暂停使用或安排上门；系统不远程指导客户自行拆 J03。
11. **挂起不跨单传播**：同一维修单按一把椅；跨单 `associated` 只保留上下文。
    OX5 同信另提的 CY-B17 缝线脱开是另一把椅、另一类问题，独立核实处理，不被 OX1 挂起连带。
